## 加速 Uncommitted Changes 展示（优先级：高）
- 目标：降低首次打开“未提交变更”详情的感知时延，目标 < 1s。
- 方案建议：
  - 预拉取与缓存：在仓库加载完成后并发获取 `getUncommittedDetails` 关键轻量数据（文件列表、统计摘要），进入详情时优先渲染骨架/摘要，再补全细节；
  - 渐进式渲染：按文件分批渲染到页面（requestAnimationFrame/微任务拆分），避免一次性大 DOM 带来的卡顿；
  - 并发策略：对 `git status --porcelain` 与必要的 `git diff --name-status` 并发执行，减少串行等待；
  - 超时兜底优化：5 秒兜底由“直接比较视图”改为“先展示文件列表 + 懒加载 diff 片段”，提升可见性；
  - 可观测性：log 埋点记录每段耗时；在 `web/main.ts` 标注加载阶段（请求→收到→渲染）。

## Tag 面板（与分支面板对齐）
- 右侧工具栏新增 `tags` 按钮，点击在 Dock 中显示标签面板：
  - 单击：选中高亮；
  - 双击：在左侧提交表定位到对应 commit，并闪烁高亮（沿用 `scrollToCommit` + `flash` 机制）；
  - 右键菜单：
    - Checkout Tag（checkout 到该标签，提示将进入 detached HEAD）；
    - Push Tag（选择远程或默认推送）；
    - Delete Tag（本地删除）；
    - Delete Remote Tag（可选：远程删除，若配置/权限允许）；
- 数据来源：沿用现有 `getRefs` 中的 tags；若必要，可在 `getRepoInfo` 返回 tags 列表以简化前端初始化展示。
- 复用样式与结构：
  - UI 与 `BranchesWidget` 尽量共用组件与样式；
  - 颜色：标签图标使用紫色（建议 `#8a2be2`），保持与分支区分。
