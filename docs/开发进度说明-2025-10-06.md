# 开发进度说明（2025-10-06）

本说明用于同步最新一轮开发进展、已完成内容与未解决问题，便于后续协作与验收。

## 本轮目标与范围
- Panel 模式体验增强：Docked 宽度记忆、侧栏按钮互斥行为、hover 提示完善。
- 稳定性修复：确保“提交详情”在普通提交与 Uncommitted Changes 下均可打开。
- 易用性优化：搜索条在 Docked 下的可见性/布局、放大镜按钮的开关行为。

## 已完成
- Docked 宽度比例化与持久化：
  - 前端新增 `settingsDockPct`（默认 0.3），拖拽结束后存为比例；
  - 显示时优先读取 `settingsDockPct`，检测到历史 `settingsDockWidth`（像素）自动迁移为比例并保存；
  - Panel 模式补齐 `setRepoState` 持久化（`src/gitGraphPanelView.ts`），关闭/重开面板能还原比例。
- 提交详情加载命令修复：
  - `git show` 参数顺序调整为 `git show --quiet --format=… <commitHash>`；
  - 影响函数：`src/dataSource.ts` → `getCommitDetailsBase`。
- 侧栏按钮 hover 提示：
  - 分支（Branches）、远程（Show/Hide Remote Branches）、查找（Find）、设置（Settings）、终端（Open Terminal）、获取（Fetch）、刷新（Refresh）补齐 `title`；首次渲染即为中文提示；
  - 刷新按钮初始渲染即带“刷新”标题。
- Docked 模式按钮互斥（轻量版）：
  - 新增“分支面板”（BranchesWidget）：点击侧栏“分支”图标在 Dock 中展示本地/远程分支列表；
  - 分组逻辑：本地分支按路径分组，远程按远程名分组（origin/work/...），均支持展开/收起；
  - 交互：点击本地分支→直接切换；点击远程分支→检出为本地新分支（跟踪远程）；
  - 与“仓库设置”互斥同区域显示；
  - 仍保留 Docked 预留空间，避免遮挡提交区。

- 分支面板右键/双击菜单（层级修复）：
  - 双击或右键分支项弹出上下文菜单（复用 Git Graph 原生菜单：Checkout Branch / Merge / Rebase / Diff with working tree / Pull / Fetch into local / Push / Rename / Delete …）；
  - 修复 Dock 内菜单被覆盖问题：菜单渲染到 Dock 容器内，使用更高层级（.dockMenu z-index=100），不再被面板遮挡。

- Uncommitted Changes 降级兜底：
  - 请求“未提交变更”详情超过 5 秒仍在加载时，自动切换到“比较视图（HEAD vs Working Tree）”，直接展示文件变更列表；
  - 优先通过表格中的两行（Uncommitted / HEAD）构建比较上下文，确保完整渲染；找不到元素时退回直接请求比较数据。

- Dock 切换动画优化：
  - Dock 模式下关闭/打开右侧面板不再使用“上滑”动画（transition:none），避免宽度不一致与双动画叠加；
  - 点击“设置”前自动关闭“分支”，点击“分支”前自动关闭“设置”，保证“抢占式单面板”。
- 搜索条适配：
  - Docked + 设置打开时，搜索条右侧偏移 = 侧栏宽度 + Docked 宽度 + 20px；
  - 放大镜支持 toggle（再次点击关闭）。
- 构建与产物：
  - 已通过本地编译与打包，产出 `git-graph-1.30.1.vsix` 用于安装验证。
