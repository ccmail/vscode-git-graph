# 2025-10-09 里程碑：提交级推送 Dock 化

## 主要改动
- 新增设置 `git-graph.pushCommit.viewMode`（`package.json`, `package.nls*.json`, `src/config.ts`, `src/types.ts`），前后端初始状态同步（`src/gitGraphView.ts`, `src/gitGraphPanelView.ts`）。
- 抽象推送对话会话 `web/pushCommitSession.ts`，在 Modal / Dock 两种模式复用预览、候选与尺寸记忆逻辑。
- 新增 Dock Widget `web/pushCommitWidget.ts`，并在 `web/main.ts` 中统一调度、互斥关闭 Settings / Branches 面板。
- 样式与资产调整：`web/styles/dialog.css`, `web/styles/pushCommitWidget.css`。

## 影响范围
- 推送对话框（提交级推送入口）。
- Dock 模式布局与宽度持久化（共享 `settingsDockPct`）。
- 配置同步（扩展设置 → 前端 initialState）。

## 验收清单
- 在 `git-graph.pushCommit.viewMode = Docked` 且 `git-graph.panel.settingsWidgetMode = Docked` 时，右键提交→推送：
  1. Dock 面板占位贴边，内容与 Settings / Branches 互斥；
  2. 拖拽分隔条可调整宽度并在同仓库记忆；
  3. 按钮禁用/启用状态随远程 / 分支输入变化。
- 将 `git-graph.pushCommit.viewMode` 改为 `Modal` 后重新打开推送对话框：仍呈现原弹窗行为。
- 切换仓库/刷新数据时，Dock 面板自动收起，状态不泄露到其他仓库。
