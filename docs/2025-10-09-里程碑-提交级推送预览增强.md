# 里程碑：提交级推送预览增强（2025-10-09）

## 主要改动
- 推送对话框新增可输入的分支组合框，支持候选过滤、最近使用分支提示及新建分支文案。
- 预览区域新增 “Commits / Files” 切换，展示 `<remote>/<branch>..commit` 的提交卡片与文件变更列表。
- 后端补齐 `pushCommitPreview` / `pushCommitToBranch` 消息处理，统一前后端类型并在无远程分支时回退到父提交差异。
- 对话框定位与尺寸：弹窗改为视图居中显示并固定 420px 宽，避免被 Dock 遮挡。
- 交互优化：自定义远程分支候选下拉支持点击展示所有远程分支并保留“新建远程分支”提示；推送模式改为下拉选择，附带 Git 参数说明；推送对话框支持拖拽调整大小并记忆上次尺寸。

## 影响范围
- 后端：`src/dataSource.ts`、`src/gitGraphView.ts`、`src/gitGraphPanelView.ts`、`src/types.ts`
- 前端：`web/main.ts`、`web/styles/dialog.css`

## 验收清单
- 右键提交触发推送窗口，远程下拉及分支输入框联动刷新预览；新分支时提示“远程分支尚不存在”。
- Commits 视图列出远程差集提交，并显示作者与时间信息；Files 视图列出增删改文件及状态标签。
- 切换远程/分支后预览自动刷新，无需关闭对话框；推送成功后视图刷新。

## 已知问题
- 最近使用分支持久化仍待实现，当前为会话级记忆。
- 文件视图暂未展示增删行统计，后续可视需求补充。
