# 里程碑：设置项国际化与面板设置页语言统一（2025-10-05）

本次里程碑聚焦于“设置项翻译优化”，目标是在 VS Code 设置页与 Webview 面板设置页两端，尽可能做到中英文一致、可切换、且文案完整。

## 背景与目标
- 背景：之前存在“设置项说明未翻译”与“已翻译但不随语言切换”的问题；同时，面板内设置页（Settings Widget）有较多中文硬编码，英文模式下仍显示中文。
- 目标：
  1) VS Code 设置页：将 Git Graph 的全部设置说明/枚举说明改为 NLS 键，随 VS Code 显示语言切换中英文；
  2) 面板设置页：接入轻量 i18n（t/tl），跟随 `git-graph.language` 切换中英文；
  3) 统一“语言设置”命名：新增 `git-graph.language`，兼容旧 `git-graph.uiLanguage`，并在语言切换时自动刷新 Webview。

## 主要改动
- 新增设置键：
  - `git-graph.language`：`auto | en | zh-CN`；新增至 `package.json`，说明在 `package.nls*.json`；
  - 兼容旧键 `git-graph.uiLanguage`（已标注 deprecated）。
- 设置说明全面 NLS 化：
  - 将 `contributes.configuration.properties` 下所有说明/标题/枚举说明统一替换为 NLS 占位符 `%setting.…%`；
  - 大量补齐 `package.nls.zh-cn.json` 的中文说明与 `enumDescriptions`；英文保持在 `package.nls.json`；
  - 注意：设置项“名称”（例如 Git‑graph › Dialog › Merge: No Fast Forward）由 VS Code 生成，规范上不可本地化，因此始终显示英文；可本地化的是“说明”和“枚举说明”。
- Webview 设置页（Settings Widget）语言统一：
  - 将硬编码中文替换为 `t/tl` 轻量 i18n（见 `web/settingsWidget.ts`）；
  - 中英文 tooltip/按钮文案/表头同步补全（General/用户信息/远程配置/Issue 链接/Pull Request 集成等全部区块）。
- 语言切换联动：
  - `src/config.ts`：`uiLanguage` 读取优先 `git-graph.language`，回退 `git-graph.uiLanguage`；
  - `src/gitGraphView.ts`：监听配置变更，`git-graph.language` 或旧键变化时自动刷新当前 Webview。

## 验收清单
- VS Code 设置页（切 VS Code 为 zh‑CN）：
  - 所有设置项的“说明/枚举说明”均为中文；切到英文后为英文；
  - 个别专有名（如 Emoji）保留英文不影响理解；
  - 设置项“名称”依平台限制保留英文，符合 VS Code 规范。
- 面板设置页：
  - `git-graph.language=en/zh-CN/auto` 时，面板设置页正文与提示随之切换；
  - 远程配置区块的 tooltip、按钮（Fetch/Prune/Edit/Delete 等）与表头（Remote/Type/Actions）语言一致；
  - Issue 链接与 Pull Request 集成表单/描述均随语言切换；
  - 仍保持此前 Panel 侧栏布局与交互修复的行为一致性。

## 影响范围
- 配置文件：`package.json`、`package.nls.json`、`package.nls.zh-cn.json`；
- 后端：`src/config.ts`、`src/gitGraphView.ts`、`src/extension.ts`（配置变更刷新）；
- 前端：`web/settingsWidget.ts`（i18n 接入与文案统一）。

## 已知限制
- VS Code 设置页中“设置项名称”不能本地化，语义说明与枚举说明可本地化（已完成）。
- 若用户切换 VS Code 语言，需要重载窗口后设置页文案才会根据 `package.nls.*` 生效（VS Code 机制）。

## 使用与说明
- VS Code 设置页：
  - 搜索 `@ext:mhutchie.git-graph` 可查看全部设置；
  - 设置说明来自 `package.nls.*`，随 VS Code 语言切换。
- 面板设置页：
  - 语言跟随 `git-graph.language`（`auto` 会基于浏览器语言推断 `en/zh-CN`）。
