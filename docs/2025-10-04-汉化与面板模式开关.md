# Git Graph 本地改造工作总结

日期：2025-10-04

## 背景与目标
- 目标一：为 Git Graph 提供中/英双语界面，可在运行时切换。
- 目标二：增加一个开关，控制 Git Graph 在“编辑器页签（editor）”或“底部面板（panel）”中展示。

## 主要改动
- Webview 侧轻量 i18n：
  - 新增 `t(text)` 与 `tl(en, zh)` 两个方法（位于 `web/utils.ts`），统一替代原先的 `L/LN`，并集中管理文案字典。
  - 覆盖范围包括工具栏提示、表头、加载态、上下文菜单、对话框按钮/提示等（`web/main.ts`、`web/settingsWidget.ts`、`web/findWidget.ts`、`web/dialog.ts`）。
  - HTML `<html lang>` 随设置动态切换，已在 `src/gitGraphView.ts` 中实现；监听 `git-graph.uiLanguage` 变更并刷新 Webview（`src/extension.ts`）。

- VS Code NLS（扩展贡献）接入：
  - 新增 `package.nls.json` 与 `package.nls.zh-cn.json`；将 commands 标题与多项设置描述迁移为 NLS 占位（`package.json` 使用 `%key%`）。
  - 已覆盖：常用命令，以及 `commitDetailsView.*`、`openNewTabEditorGroup.*`、`referenceLabels.alignment.*`、`keyboardShortcut.scrollToStash`、`markdown`、`maxDepthOfRepoSearch`、`uiLanguage` 等设置。

- 新增展示位置开关：
  - 新增 `git-graph.viewLocation`（`editor` | `panel`，默认 `editor`），用于控制展示位置。
  - 当为 `editor`：保持原有行为，在编辑器页签打开。
  - 当为 `panel`：实现了面板模式的 MVP 版本，注册了 `viewsContainers.panel` 与 `views`，并新增 `GitGraphPanelViewProvider`（`src/gitGraphPanelView.ts`）。
    - 面板版 Webview 复用大部分初始化逻辑与消息通道（`loadRepos` / `loadRepoInfo` / `loadCommits` / `loadConfig` / 打开文件与外链等）。
    - `git-graph.view` 命令根据 `viewLocation` 路由：`editor` 走 `GitGraphView.createOrShow`，`panel` 通过 `git-graph.viewPanel.focus` 聚焦面板，并传递初始仓库（`src/commands.ts`）。

- 引擎与类型升级：
  - `package.json` 将 `engines.vscode` 升级至 `^1.50.0`，`@types/vscode` 升级至 `1.50.0`，以支持面板 API（WebviewView）。
  - 补充了一个最小化的 `src/vscode-shims.d.ts`，确保类型缺失环境下仍可编译（兼容旧环境）。

- 规范修复：
  - 遵守项目要求（CRLF、Tab 缩进、零告警），清理本轮改动产生的 Lint 告警，使 `npm run compile` 正常通过。

## 兼容性与已知限制
- 面板模式（WebviewView）需要 VS Code 版本 ≥ 1.50 才具备完整 API；若在较旧环境使用，`src/vscode-shims.d.ts` 仅保证编译通过，不保证运行时存在全部能力。
- 面板版目前为 MVP：已覆盖核心加载/刷新/基本交互，部分编辑器侧的少量命令尚未全部迁移；后续可逐步补齐以达到与编辑器模式一致的功能完备度。

## 验证与使用
- 语言切换：
  - 设置 `git-graph.uiLanguage` 为 `auto|en|zh-CN`，运行时变更会自动刷新 Webview 文案。
- 展示位置：
  - 设置 `git-graph.viewLocation` 为 `editor`（编辑器标签）或 `panel`（底部面板）。
  - 通过命令面板执行 `Git Graph: View Git Graph`，按设置在对应位置展示。
- 构建：
  - `npm run compile` 可正常完成打包；若有本地差异导致 Lint 报错，请确保改动文件为 CRLF + Tab 缩进，并执行 `npm run lint -- --fix`。

## 提交与推送
- 本地尝试 `git commit` 时遇到 `.git/index.lock` 权限问题（Operation not permitted），未在自动流程中提交。
- 请在仓库根目录手动执行：
  - `git add -A`
  - `git commit -m "feat(i18n): 引入中英双语与 NLS；新增 viewLocation（editor/panel），实现面板模式 MVP"`
  - `git push origin develop`
- 如仍提示 `index.lock`，可先确认无其他 Git 进程占用，必要时手工删除锁文件：`rm -f .git/index.lock`。
