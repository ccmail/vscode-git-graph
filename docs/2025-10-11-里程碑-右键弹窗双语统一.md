# 主要改动
- 统一分支、远程分支、提交、贮藏、标签、未提交更改等右键菜单弹窗的提示语与按钮文字，改用 `tl()`/`t()` 提供中英文文案（`web/main.ts`）。
- 新增标签详情弹窗、多仓库推送提示、刷新按钮等 UI 提示的中文翻译（`web/main.ts`）。

# 影响范围
- Webview 侧所有右键操作对话框及其运行状态提示。
- 推送标签时的远程缺失校验弹窗内容。
- 标签详情查看面板。

# 验收清单
- 在分支、远程分支、提交、标签、贮藏及未提交更改列表中触发右键操作，确认弹窗标题、正文、按钮均能随 UI 语言切换。
- 手动执行 `npm run lint`、`npm run compile`，保证无构建错误。
- 安装 `git-graph-1.30.4.vsix` 验证弹窗语言显示正确。
