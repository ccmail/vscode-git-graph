# 开发进度说明（2025-10-07）

本说明用于同步本轮（10-07）开发进展、已完成内容与后续计划，便于验收与跟进。

## 本轮目标与范围
- 修复并完善“提交级推送（Push Commit）”能力：从提交右键菜单发起，将远端分支更新至所选提交。
- 提升可用性：远程/分支可选与新建、推送模式说明、预览展示格式、Panel 模式消息补齐不再卡住。
- 清理分支栏菜单中的误置项，保持“推送此前提交(含选中commit)”仅出现在提交右键菜单。

## 已完成
- 提交级推送（含模式选择与预览）：
  - 前端：`web/main.ts` 提交右键 → “推送(push)此前提交(含选中commit)”
    - 打开对话框，展示预览 commit 列表（左对齐、卡片式）
    - 选择 Remote 下拉、Branch 文本输入（支持新建远程分支）、Mode（Normal/Force With Lease/Force，带中文说明）
    - 点击 Push → 执行 `git push <remote> <commit>:<branch>`，仅将远端更新到该提交
  - 后端：
    - `src/dataSource.ts` 新增 `pushCommitToBranch`、`getCommitsBetween`、`getBranchesContainingCommit`
    - `src/gitGraphView.ts` / `src/gitGraphPanelView.ts` 补齐 `pushCommitToBranch` / `pushCommitPreview` 消息处理
  - Panel 卡住问题：新增响应分支 `pushCommitToBranch`，前端收到后 `refreshOrDisplayError(...)` 关闭“正在执行”
- 菜单清理：
  - 已移除分支/远程分支右键中的“推送此前提交(含选中commit)”，仅保留于提交右键菜单中
- 预览展示优化：
  - 预览列表左对齐、卡片化、hash 徽章、保留换行
- 打包：`git-graph-1.30.4.vsix`

## 待解决问题

- Branch 组合框：当前以文本输入支持“新建”与指定；后续计划改造成“可输入+候选过滤”的组合框，并在切换时实时刷新预览。

## 验收建议
- 在提交表右键任一 commit：
  - 对话框显示 Remote / Branch / Mode 与预览列表
  - 输入一个不存在分支名（如 `review/x`）后推送，远程应出现新分支且指向选中 commit
  - 切换 Mode 的说明清晰；Normal 下非快进应报错；Force With Lease/Force 能覆盖（谨慎验证）
- 分支栏右键菜单不再包含“推送此前提交(含选中commit)”

## 下一步计划

  - 候选：包含该提交的本地分支 + 当前分支 + 常用分支（最近使用/收藏）
  - 输入过滤候选；输入新名称时显示“新建远程分支 <name>”，回车后将该名称作为推送目标
