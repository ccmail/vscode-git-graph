# 里程碑：Docked 宽度持久化与交互修复（2025-10-06）


本里程碑聚焦于 Panel 模式下的“Docked 区域宽度记忆、提交详情加载可靠性、侧栏按钮交互一致性”等问题，围绕“恢复体验一致、减少遮挡、便于跨分辨率使用”展开。

## 主要改动
- Docked 宽度按比例持久化：
  - 前端在拖拽结束后，将像素宽度转换为比例 `settingsDockPct`（默认 0.3，约 70/30）。
  - 显示时优先读取 `settingsDockPct`；检测到历史字段 `settingsDockWidth`（像素）时自动迁移为比例并保存。
  - Panel 模式新增消息处理：在 `src/gitGraphPanelView.ts` 中实现 `setRepoState` 持久化（含 `settingsDockPct`），关闭/重开面板会按上次比例还原。

- 提交详情加载（Uncommitted Changes 与普通提交）命令修复：
  - 统一 `git show` 参数顺序为：`git show --quiet --format=… <commitHash>`；避免“选项必须在非选项参数前”的报错。
  - 影响函数：`src/dataSource.ts` 中 `getCommitDetailsBase`。

- 侧栏 Hover 提示补全：
  - 为分支（Branches）、远程开关（Show/Hide Remote Branches）、查找（Find）、设置（Settings）、终端（Open Terminal）、获取（Fetch）、刷新（Refresh）补齐 `title`，首渲染即为中文标题（如“刷新”）。

- 分支面板（初版）：
  - 新增 Dock 内“分支面板”（BranchesWidget），在右侧 Dock 展示本地/远程分支树；
  - 点击本地分支可直接检出；点击远程分支会检出为本地新分支并跟踪远程；
  - 与“仓库设置”互斥显示，复用 Dock 宽度与拖拽；
  - 后续将补充更多分支操作与筛选。

- 搜索条与 Docked 的可见性优化：
  - 当 Docked + 打开设置时，搜索框右侧偏移 = 侧栏宽度 + Docked 宽度 + 20px；左侧布局亦适配。
  - 放大镜按钮支持 toggle（再次点击关闭）。

## 影响范围
- 配置与文案：`package.json`、`package.nls*.json`（部分按钮 `title` 补齐/统一）。
- 后端：`src/gitGraphPanelView.ts`（新增 `setRepoState` 处理）、`src/dataSource.ts`（`git show` 参数顺序修复）。
- 前端：`web/settingsWidget.ts`（比例持久化与像素→比例迁移逻辑）、`web/main.ts`/`web/findWidget.ts`（搜索条偏移与按钮 toggle）、相关样式文件。

## 验收清单
- Docked 宽度：拖拽 → 关闭 → 重开，能按上次比例恢复；跨分辨率表现稳定（以比例存储）。
- 提交详情：普通提交与 Uncommitted Changes 的“提交详情”均能正常打开，无参数顺序错误。
- 侧栏 Hover：分支/远程/查找/设置/终端/获取/刷新均有中文提示，首次渲染即可见。
- 互斥行为：Docked 模式下点击“分支”不遮挡提交区域；“设置”支持开关；两者互斥占位符合预期。
