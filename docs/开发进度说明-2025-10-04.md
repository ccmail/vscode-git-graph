# 开发进度说明（2025-10-04）

本说明用于同步近期开发进展、已实现功能与未完项，便于后续协同与验收。

## 项目背景（给下一位 AI 工程师）
- 项目类型：VS Code 扩展“Git Graph”的定制版，核心是通过 Webview 呈现 Git 历史图与操作。
- 定制目标：
  - 汉化 Webview 文案，改善中文用户体验；
  - 新增 Panel 模式并优化布局（侧栏贴边、节省空间）；
  - 让状态栏入口与视图打开位置配置保持一致；
  - 添加快捷终端入口，提升常用操作效率。
- 基线版本：上游 1.30.0；当前项目版本 1.30.1（本地定制）。
- 技术栈与结构：
  - 后端（扩展主进程）：TypeScript，位于 `src/`，输出到 `out/`；
  - 前端（Webview）：TypeScript + CSS，位于 `web/`，打包到 `media/`；
  - 配置与 NLS：`package.json`、`package.nls*.json`；
  - 测试：Jest（`tests/`）。

### 代码导览（常用入口）
- `src/config.ts`：统一读取 VS Code 设置（含新增的 `git-graph.panel.controlsPosition`）。
- `src/commands.ts`：命令注册与入口（含新增 `git-graph.openRepoTerminal`）。
- `src/statusBarItem.ts`：状态栏按钮（“Git Graph”与“终端”）。
- `src/gitGraphView.ts`：Editor 模式的 Webview 提供方（原实现，完整消息处理）。
- `src/gitGraphPanelView.ts`：Panel 模式的 Webview 提供方（本项目新增/强化，已补齐提交详情等消息处理）。
- `web/main.ts`：Webview 前端主逻辑（渲染表、图、详情；新增侧栏按钮行为）。
- `web/styles/main.css`：Webview 样式（新增 Panel 侧栏贴边布局、图标垂直排列等）。
- 其他：
  - `web/graph.ts`（绘制提交图），`web/dropdown.ts`（下拉），`web/settingsWidget.ts`（设置面板）。

### 开发/编译/打包（快捷指南）
- 安装依赖：`npm install`
- 全量编译：`npm run compile`
- 仅后端：`npm run compile-src`
- 仅前端：`npm run compile-web`
- 打包 VSIX：`npm run package`（或使用已生成 `git-graph-1.30.1.vsix` 验证）

## 使用说明（要点）
- 位置一致性：
  - `git-graph.viewLocation` 设为 `panel` 时，状态栏/命令入口均在 Panel 打开；设为 `editor` 时在标签页打开。
- Panel 控制栏位置：
  - `git-graph.panel.controlsPosition` 取值 `Top/Left/Right`，默认 `Right`。
- 侧栏快捷按钮：
  - 分支（Branch 图标）：点击打开/聚焦 Branches 下拉。
  - 远程开关（Eye 图标）：切换“Show Remote Branches”。
  - 其余：查找、终端、设置、拉取、刷新。
- 打包安装：
  - 通过 VS Code “Install from VSIX…” 安装 `git-graph-1.30.1.vsix`；如遇需重启提示，请先退出编辑器后再安装。

## 兼容性与规范

- 代码规范：TypeScript、Tab 缩进、单引号、分号、1TBS 花括号；CRLF 换行，禁止 console/eval（使用内部日志工具）。
