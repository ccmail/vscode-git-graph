# 里程碑：分支检出卡住修复（2025-10-06）

## 主要改动
- Panel 模式补齐分支/提交检出消息处理：
  - `src/gitGraphPanelView.ts` 新增处理：`checkoutBranch`、`checkoutCommit`；
  - 对应实现与 Editor 模式（`src/gitGraphView.ts`）对齐：
    - `checkoutBranch` 成功后若附带 `pullAfterwards`，继续调用 `pullBranch`，将结果并入 `errors` 数组；
    - 统一通过 `web/main.ts` 的 `refreshAndDisplayErrors` 路径驱动刷新与关闭“正在执行”对话框。

## 影响范围
- Panel 模式下的“分支检出”“检出到指定提交”行为；
- 远程分支检出后立即 Pull 的复合动作（错误信息与刷新时序）。

## 验收清单
- 在 Panel 模式：
  - 本地分支执行“Checkout Branch”，动作完成后刷新正常，“Checking out Branch ...” 提示自动关闭；
  - 远程分支执行“Checkout Branch”，必要时包含 Pull，动作完成后刷新正常；
  - 任何错误能以错误对话框展示，不会卡住在“正在执行”。

## 已知问题
- 若仓库存在未解决冲突或 HEAD 分离的特殊状态，git 原生命令可能返回交互式提示；当前行为与 Editor 模式一致，保持由 git 返回错误信息，前端弹窗提示。
